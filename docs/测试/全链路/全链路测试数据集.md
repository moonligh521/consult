# 挂号全链路测试数据集（N1 → N9）

面向「22 个一级科 / 137 个二级科」挂号准确度规格做的可跑数据集。**总量 150,000 条**：
每行 = 一套输入 + 复刻器算出的全链路期望 + 规格金标 + 一条机器可校验的断言。

标签不是猜的：全部由 `rule_replica_v2.py` 按 Java 侧规则算出来，评测时再重放一遍校验。

---

## 1. 文件清单

| 文件 | 作用 |
|---|---|
| `triage-cases.csv` | 数据集本体，150,000 行 × 32 列（UTF-8 BOM，Excel 可直接打开） |
| `rule_replica_v2.py` | 规则复刻器：N1 安全 / N2 含糊 / N3 槽位 / N4 归约 / N5 症状 / N6 挂科 + TriageEngine 融合 |
| `build_triage_cases.py` | 生成器：核心词条 × 槽位 × 口吻 × 噪声 + 各专项集合 |
| `gold_137.py` | 137 个二级科的规格金标主诉（规格第三节的输入模板） |
| `gold_assert.py` | 边界/负向/安全/槽位用例的规格断言（token 形式） |
| `score_triage_cases.py` | 评测：自检 → 覆盖率 → 重放 → 指标 → 断言通过率 |
| `dump_gaps.py` / `gaps.txt` | 导出「规格期望 vs 现网产物」的差距清单 |

单一事实来源（不手抄关键词）：

- 科室 / 二级科 / 挂词 / 病名 / 错别字 / 不确定标记 / 歧义词 / 归约同义
  → `consult-registration-agent-service/src/main/resources/department/catalog-seed.json`
- 急症与转人工规则（BASELINE 已发布 / DRAFT 影子）
  → `consult-registration-agent-service/src/main/resources/safety/urgent-catalog.json`

## 2. 怎么跑

```powershell
cd docs/测试/全链路
$env:PYTHONIOENCODING='utf-8'

python build_triage_cases.py      # 生成 triage-cases.csv（约 2 分钟）
python score_triage_cases.py      # 自检 + 覆盖 + 重放 + 指标 + 断言通过率
python dump_gaps.py               # 导出 gaps.txt
```

生成器可只跑子集：`python build_triage_cases.py --cores 30 --target 2000 --no-pad --out _q.csv`。
提醒：`| Select-Object -First N` 会中断写文件进程，跑生成器请重定向到日志。

## 3. 列说明

| 列 | 含义 |
|---|---|
| `case_id` / `suite` / `node` / `case_ref` | 编号、集合、节点（N1–N9）、规格用例号（B1 / NB9 / N11…） |
| `action` / `turn` / `prior_input` | 这一步做什么（发消息/确认/改卡/派医生/下单）、第几句话、上几句 |
| `scenario` | 仅 N7–N9：`MODEL-ON-CERTAIN`、`DOC-FULL`、`ORDER-TWICE`、`ENFORCE`… |
| `input` / `session_gender` / `session_age` | 患者这句话；绑就诊人补的性别/年龄（不在原话里） |
| `expect_status_*` / `expect_missing_slot` | 会话状态（1 待描述 … 8 渠道不适用）、还缺哪个槽 |
| `expect_safety_*` | N1 结论 `URGENT`/`NEED_HUMAN`/`UNSUITABLE`/`PASS` + 命中规则 + 影子规则 |
| `expect_canon_*` / `expect_terms` | N4 归约：原因码、来源（RULE/FALLBACK）、抽到的病名 |
| `expect_symptoms` | N5 症状标签 |
| `expect_department*` / `expect_specialty` | N6 卡片一级科 / **二级科（判分主指标）** |
| `expect_route_reason` / `_source` / `_certainty` | 融合后原因码、来源、确定性 |
| `expect_route_reason_rule` | **规则首轮原因码**（CONFLICT/AMBIGUOUS_ONLY 融合后变 `MODEL_UNAVAILABLE`，两列都要断言） |
| `expect_error_code` | N7–N9 错误码（1105 / 1115 / 1117 / 1119 / 1123 / 1305 …） |
| `gold_department` / `gold_specialty` / `gold_hit` | **规格期望**（不是当前代码产物）与是否命中 |
| `countable` | 是否计入「二级科 Top1」分母 |
| `spec_assert` | 机器可校验断言 |
| `variant_*` / `remark` | 这条是怎么从核心词条变出来的、人工备注 |

`spec_assert` token（`;` 分隔表示「或」）：

```
SPECIALTY:X / NOTSPECIALTY:X / NOTDEPT:X
STATUS:X     URGENT|NEED_HUMAN|CARD_READY|NEED_DESCRIPTION|NEED_SLOT|CONFIRMED
SAFETY:X     URGENT|NEED_HUMAN|UNSUITABLE|PASS
SHADOW:RULEID        DRAFT 影子必须命中
SLOT:X | NOSLOT      GENDER/AGE/DURATION
REASON:X | FINAL:X | ERROR:CODE
```

### 三条口径约定（读指标前必看）

1. **`route()` 才是卡片口径，`advise()` 不是。** 无病名、无症状时 `route()` 也会走 `firstRouting`（含一级科名），
   「挂内科 → 普内科」「挂皮肤性病科 → 皮肤科」与卡片一致。`DepartmentRouterTest` 仍有一批 `advise()` 样例，
   本数据集在 S1/S2 里只校二级科。

2. **`gold_*` 是规格期望，`expect_*` 是当前代码产物。** 两者不一致 = 待决事项（目录缺口 or 代码 bug），
   全量列在 `gaps.txt`，不算代码回归失败。`spec_assert` 全部成立时 `gaps.txt` 写「无」。

3. **分母**：只有 `countable=1` 的行进 Top1 分母。定义是「这条词的基线本就该落目标二级科，
   且这层包装不引入儿童标记 / 儿童年龄 / 跨性别 / 中医词 / 错字 / 缺槽」。
   一句话：指标量的是**同一句口语换包装后结论不能变**的鲁棒性；非锚点词条（基线就不落本科，25 个，
   多为歧义词如失眠/头晕）不进分母。口语扰动 S19–S25 计入另一层 Top1，不进规格断言。

## 5. 当前结果（`python score_triage_cases.py`）

```
自检（Java 单测 + 规格必过样本）         83/83 通过
覆盖率                                二级科 137/137；安全规则 16/16；B1–B20 / NB1–NB15 / N1–N20 齐全
重放（期望 vs 当前复刻器）               150,000 行全一致
书面语 Top1（计入分母 16,975 行）        99.99%    口语扰动 Top1 67.90%
S2 规格金标137 Top1                    100.00%
S13–S15 spec_assert                    4,500 / 5,400 / 3,600 全部成立
边界/负向/安全/槽位断言                   0 行不成立
```

状态分布：卡片待确认 114,598 / 待补槽 31,529 / 已确认 1,800 / 需要人工 1,753 / 急症分流 211 / 待描述 104 / 渠道不适用 5。

N6 原因码分布：SINGLE_SPECIALTY 55,218、PEDIATRIC 35,424、CANON_TERM 24,343、
MODEL_UNAVAILABLE 18,355、OVERRIDE 6,547、UNCERTAIN_MARKER 5,976、PATIENT_CONFIRM 1,800、
NO_HIT_SHORT 769、SAME_L1_EARLIEST 668。

规则 CERTAIN 的行占多数，这批行禁止调模型；只有 CONFLICT / AMBIGUOUS_ONLY / NO_HIT 才走到模型，
模型不可用时统一落「全科」+ `source=FALLBACK` + `MODEL_UNAVAILABLE`。

## 7. 维护约定

- **改了 Java 规则或目录**（catalog-seed.json / urgent-catalog.json）：重跑 build_triage_cases.py，
  再跑 score_triage_cases.py。出现「重放不一致」说明期望已过期，必须重生成，**不要手改 CSV**。
- **只是口径切换**（同义词审核状态、DRAFT 是否 ENFORCE、某科停用）：用 rule_replica_v2.py 的快照派生方法
  （without_enabled / with_synonyms_reviewed / enforce_draft），评测脚本里已接线。
- **加新二级科**：先在 gold_137.py 补一条主诉，跑生成器时会自己校验 137 覆盖；漏了会在日志里点出来。
- **口语**：能穷尽的中文说法（头疼、打鼾、繁体、好几天）进目录/归一；拼音和英文不进目录，规则 `NO_HIT` 后交主诉模型。
