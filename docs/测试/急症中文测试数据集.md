# 急症中文测试数据集

文档日期：2026-10-22。  
配套数据：同目录 [`urgent-zh-cases.next.csv`](urgent-zh-cases.next.csv)（本次完整 1299 条）。[`urgent-zh-cases.csv`](urgent-zh-cases.csv) 若被 Excel/IDE 占用，以 next 为准。  
生成脚本：[`build_urgent_zh_cases.py`](build_urgent_zh_cases.py)。评测脚本：[`score_urgent_zh_cases.py`](score_urgent_zh_cases.py)。

本文件给**中国患者口吻**的导诊安全评测用。不是临床诊疗标准，不能当「这千条都该打 120」的金标准。

---

## 1. 为什么要单独整理

公开源里**没有**一份现成的「1000 条中文急症话术、标签就是该打 120」清单。

| 外源 | 规模 | 对本系统 |
| --- | --- | --- |
| FedMML / TriageAide 合成急诊 | 8.7 万，ESI 1～5 | 英文、合成；ESI-2 不等于拨 120 |
| MIMIC-IV-ED / MIETIC | 约 0.9 万～40 万急诊主诉 | 要 PhysioNet 资质，英文病历腔 |
| NHAMCS | ESI-1+2 约 9400 | 编码主诉多，不是口语 |
| emergencyQA | 240 条红旗问句 | 最像测试话术，但是英文、只有 240 |
| TIMed-Q | 急诊相关约 100 条 | 不够 |
| 京东健康分科 / 好大夫 / MedDialog | 中文问诊很大 | **分科室**，没有急症标签 |

所以本集是：**按中国患者说法原创整理**，标签对齐本仓库当前目录（`urgent-catalog.json` 2026.10.0），用来测漏报、误报和影子规则。

## 2. 标签口径（必须按这个读 CSV）

生产环境 `draft-mode=SHADOW`。

| CSV「分组」 | 生产是否应 120 | 期望 |
| --- | --- | --- |
| 正式应拦 | 是 | 对外状态急症(3)，改卡/确认/下单均拒绝 |
| 影子观察 | 否 | 不 120；审计 `shadowRuleIds` 含对应 DRAFT 规则 |
| 已知漏报 | 否 | 临床上像急症，**当前目录没有别名**，用来观察漏诊 |
| 反例不应拦 | 否 | 普通咳嗽、头痛等，走补槽或出卡 |
| 描述含糊 | 否 | 待描述(1)，不进选就诊人 |
| 转人工 | 否 | 转人工(6)。含：转人工、找人工、人工客服、转人工客服、接人工客服、转接人工、找客服。否定「不要转人工」不触发；「人工智能」不触发 |
| 渠道不适用影子 | 否 | 生产只记影子；ENFORCE 才变为状态 8 |
| 优先级 | 是 | 「胸痛并且转人工」仍是急症 |
| 确认后升级 | 是 | 确认卡片后再说胸痛，仍钉死并挡住下单 |

和 ESI 的区别：ESI-3 Urgent 是急诊排队，**不是**本系统的 120。本集不把「胃痛能走路」标成急症。

否定句：基线四条按 D-15，`没有胸痛` **仍应 120**。这是已发布行为，不是笔误。

## 4. 怎么用

1. 用 CSV 里的「话术」调用 `POST /api/consultations/messages`（每次新开咨询，或按分组复用会话）。
2. 对照「生产期望状态」「生产是否应120」。
3. 影子组核对审计表 `shadow_rule_ids`，不要把影子命中当成可以上线的 120。
4. 已知漏报组：**通过才说明现状**（没 120）；不要为了把这组测绿，把词直接写进 BASELINE。

建议统计：

- 正式应拦的召回（漏了就是事故）
- 反例的误报（不该 120 却 120）
- 影子命中率（目录覆盖口语的进度）
- 已知漏报仍未命中的条数（下一批签核候选）

## 5. 分类样例

正式应拦：`胸痛两小时了` / `我爸呼吸困难` / `孩子口唇发紫` / `没有胸痛`（仍升级）。

影子观察：`胸口闷` / `喘不上气` / `口角歪斜` / `说话不清` / `吐血`。

已知漏报：`心口像压了块大石头` / `喘不过气来` / `嘴唇发青` / `口眼歪斜` / `说话大舌头`。

反例：`女，32岁，干咳半年，运动后加重`。

含糊：`有点不舒服`。

转人工：`转人工` / `人工客服` / `转人工客服` / `接人工客服` / `转接人工` / `找客服`。

---

## 6. 使用限制

- 话术为评测用原创中文，不复制 MIMIC、MedDialog、emergencyQA 原文。
- 未经过临床签核，**禁止**把「已知漏报」「影子观察」整组升成 BASELINE。
- 自伤、自杀相关条目只用于拦截评测，产品上线需另配值班与转介流程。
- 目录变更后应重新跑本 CSV，并更新「期望影子规则」。

重新生成：

```text
python docs/测试/build_urgent_zh_cases.py
```
