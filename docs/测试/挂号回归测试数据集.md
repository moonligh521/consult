## 1. 有没有现成工具：结论

**没有可以直接拿来用的。**

| 候选 | 为什么用不了 |
| --- | --- |
| MIMIC-IV-ED / MIETIC / NHAMCS | 要 PhysioNet 资质；英文病历腔，不是患者口语；ESI-2 不等于拨 120 |
| emergencyQA / TIMed-Q | 英文；240 条量级，且无科室标签 |
| 京东健康分科 / 好大夫 / MedDialog / cMedQA | 中文问诊量很大，但只有**科室**标签，没有**急症**标签；科室体系（几十个科）与本仓库开通的 10 个科对不上 |
| Faker / 合成数据库 | 只造姓名地址，造不出「我爸心口像压了块大石头」这种主诉 |
| 通用 LLM 直接生成 | 能扩写口语，但**不能让模型打标签**——标签必须来自规则引擎，否则测出来的不是代码行为 |

**可行方案（本次采用）**：`规则复刻器 + 口吻包装器 + 噪声注入`，标签全部由复刻器算出，话术由固定词表组合。可选增强：用 LLM 只做**话术扩写**（不给标签），再交给复刻器打标，人工抽检。

本仓库特有的两个硬约束，决定了必须自建：

1. **科室只有账号开通的 10 个**：内科、外科、男科、骨科、妇产科、口腔科、儿科、耳鼻喉科、全科、中医科。对不上词一律兜底全科，不能出现皮肤科/眼科等未开通科室。
2. **路由是纯关键词**（`DepartmentRouter.advise`）：取文中**最先出现**的关键词，同位置取**更长**的。测的就是这套位置竞争规则。

## 2. 标签体系：两套期望，别混用

| 列 | 含义 | 用途 |
| --- | --- | --- |
| 生产期望状态 / 生产是否应120 / 生产期望科室 / 生产科室依据 / 期望影子规则 | **当前代码应该给出的结果**，由 `rule_replica` 复刻算出 | **回归门禁**：代码一改，这里对不上就要人工确认是有意改动还是回归缺陷 |
| 临床期望急症 / 临床期望科室 | 从临床常识看这句话**应该**是什么结论 | **差距分析**：找漏报、误报、词典缺口。**不**用来判定构建失败 |

`生产与临床差异` 直接给出差距标签，可筛选：

| 差异标签 | 条数 | 含义 |
| --- | ---: | --- |
| 急症漏报 | 1427 | 临床该打 120，生产没拦（DRAFT 影子 + 目录未覆盖口语；`胸疼` 等错别字目前只记影子） |
| 判不了却硬定科 | 358 | 临床判不了科室且没有「说不清/不知道挂哪科」标记时，仍按先出现的关键词定科 |
| 被追问未出卡 | 97 | 本可直接出卡，却因描述短/无症状词被判含糊（注意：描述不清组的追问不计入这里，那是正确行为） |
| 急症误报 | 141 | 生产升了 120，临床不该升（`没有胸痛` 这类，D-15 已发布行为） |

## 3. 数据是怎么造出来的

### 3.1 单一事实来源

`rule_replica.py` 不手抄关键词，直接解析源码：

- 科室 + 关键词 ← `department/catalog-seed.json`（兜底必须是全科）
- 科室枚举 ← `Department.java`
- 症状短语 ← `SymptomExtractor.java` 的 `PHRASES`
- 含糊正则 ← `ComplaintClarity.java` 的 `VAGUE`
- 急症规则 ← `src/main/resources/safety/urgent-catalog.json`

代码改了关键词，重跑生成脚本，标签自动跟着变，不会悄悄漂移。

### 3.2 715 条核心说法 × 口吻包装

每条核心说法轮转套用 36 个包装器（30 种口吻 + 6 种噪声），取满 13000 条去重后停止。轮转起点用稳定哈希，保证每次生成完全一致。

**口吻维度（30 种）**：本人自述、代家属描述（爸/妈/孩子/老人/老公/老婆/儿子/女儿/奶奶/爷爷）、带年龄性别、带病程、挂号咨询口吻、礼貌前缀、口语语气词、咨询口吻。

**输入噪声（6 种）**：字间插空格、错别字（胸痛→胸疼、咳嗽→刻嗽、哮喘→孝喘…）、结巴重复、语气填充、冗长口播、标点轰炸。

噪声不是装饰：安全匹配与科室路由都做 NFKC 去空格，所以 `腹 泻 ， 咳 嗽` 会按「腹泻」定内科。错别字（`胸疼`/`刻嗽`）仍可能打不中 BASELINE。对不上词一律兜底全科。

## 4. 两个专项的设计口径

### 4.1 描述不清（该追问，不该出卡）

分 4 个子主题，覆盖患者常见的「说不出病情」：

- **笼统不适**：`不舒服` / `浑身难受` / `身体不适` / `不太对劲` / `浑身不自在` / `不得劲` / `说不清哪里不舒服`
- **无症状诉求**：`你好` / `在吗` / `帮我挂号` / `挂什么科` / `怎么挂号` / `医保能报吗` / `我要拿药` / `我来复查` / `我很担心`，以及 `嗯`、`。。。。`、`？？？`、`hi` 这类无意义输入
- **过短主诉**：`牙疼`、`皮疹`、`胸闷`、`呕吐`、`失眠`、`没劲`、`浮肿`、`肿块` —— 长度小于 6 且无可识别症状词，生产一律追问
- **但高危**：`快不行了`、`撑不住了`、`疼得受不了`、`感觉要死了`、`快没气了` —— 生产转人工（HUMAN-BASE-002），不升 120

口径：笼统不适 / 无症状诉求 / 过短主诉的**正确行为就是追问**，生产落 `待描述(1)` 记为**一致**。高危短句生产应转人工；没转到才记 `高危被当含糊`。

生成时用**短包装器**（不补性别/年龄/病程、不把句子拉长），并且**只收真正落 `待描述(1)` 的行**——包装后能出卡的会自动剔除，保证这组数据是纯的。

### 4.2 判不了科室

5 个临床场景，这些临床上本来也定不了科：

- **部位说不清**：`肚子疼，说不清哪个位置` / `浑身疼，哪儿都疼` / `疼的地方串着走`
- **跨科症状并存**：`又咳嗽又胃痛，不知道先看哪个` / `头痛还呕吐，分不清先后` / `恶心还咳嗽，不知道挂哪个科`
- **全身/非特异**：`人瘦了一大圈，查不出原因` / `低烧一个月，找不到原因` / `全身浮肿`
- **症状自相矛盾**：`一会头疼一会肚子疼` / `说不清是胃疼还是肚子疼` / `有时候咳，有时候吐`
- **要检查才定得了**：`体检查出有个结节` / `拍片说肺上有点阴影` / `化验单好几项箭头`
- **特殊人群说不清**：`孩子一直哭，说不清哪儿疼` / `老人糊涂，说不明白哪儿不舒服`

口径：**落全科算可接受兜底**（全科本来就是兜底科），**被某个先出现的关键词硬定科**才记 `判不了却硬定科`（358 条）。带 `说不清`/`不知道挂哪科`/`分不清` 的已改走全科。典型：`我爷爷胸闷还拉肚子` → 因为 `胸闷` 在前，被定成内科。

## 5. 怎么用

生成：

```text
python docs/测试/build_registration_cases.py
```

评测（自检 + 回归 + 差距分析）：

```text
python docs/测试/score_registration_cases.py
python docs/测试/score_registration_cases.py 其他.csv
```

评测输出三段：

1. **自检**：跑目录自带的 `positiveCases`/`negativeCases` 和 `DepartmentRouterTest.java` 的黄金样例（`干咳半年`→内科/干咳、`头痛两天`→内科/头痛、`胃痛三天`→内科/胃痛、`手腕骨折两天`→骨科/骨折、`体检报告看不懂`/`挂皮肤科`/`挂眼科`→全科）。**这段不过，说明复刻器和代码跑偏了，后面的结论都不可信。**
2. **回归**：CSV 里的生产期望 vs 当前代码复刻结果。本次 13000/13000 一致。这里出现不符 = 代码行为变了。
3. **差距**：生产 vs 临床，含科室混淆矩阵。

常用筛选：

- 只跑**描述不清** → 筛 `分组` 以 `描述不清` 开头
- 只跑**判不了科室** → 筛 `分组` = `判不了科室`
- 跑**正例回归** → 筛 `生产与临床差异` 为空
- 找**高危转人工** → 筛 `分组` = `描述不清-但高危`

打真实接口（可选）：把「话术」逐条 POST `/api/consultations/messages`，比对 `status` 与 `card.department` / `card.departmentEvidence`，影子组再核对审计表的 `shadow_rule_ids`。

## 6. 本次实测暴露的主要问题

按优先级：

1. **急症漏报 1427 条（11.0%）**。主体仍是 DRAFT 影子（`胸口痛`/`喘不上气`/`口角歪斜`）和目录外口语。`胸疼`/`呼息困难`/`口唇发子` 已进 DRAFT，生产仍不 120，等临床签核再升。匹配层纠错故意不覆盖这些急症错字，避免把影子纠成基线 120。
2. **判不了却硬定科 358 条（2.8%）**。带 `说不清`/`不知道挂哪科`/`分不清` 的已走全科；剩下是没有这些标记的跨科/部位不明。
3. **被追问未出卡 97 条（0.7%）**。`头通`/`刻嗽` 已能出症状；剩下多是全科短主诉和急症影子短句。
4. **急症误报 141 条**。`没有胸痛` 仍 120，D-15 已发布行为。
5. **科室漏词 / 科室误判 0**。出卡专科一致率 7377/7377（100%）。
6. **已消化**：高危短句转人工；不确定话术走全科；挂号错别字归一；对不上词一律兜底全科。

## 7. 限制

- 话术为评测用原创中文，不复制任何外部数据集原文。
- 「临床期望」是本数据集的整理意见，**未经过临床签核**，不能当诊疗标准。
- **禁止**为了把「急症漏报」测绿，直接把词写进 BASELINE。科室口语同义词可进目录，但只能挂已开通的 10 科。
- 描述不清组的「临床期望」统一是「需追问」，这是刻意设定——不是每条都真需要追问，但作为回归基线，生产追问了就算一致。
- 自伤/自杀相关条目只用于拦截评测，产品上线需另配值班与转介流程。
- 复刻器只覆盖别名匹配路径。若生产启用了 LLM 信号抽取（`DeepSeekSignalExtractor`），实际结果会超出本数据集的预测范围。
- `urgent-catalog.json` 或科室关键词变更后，必须重跑生成 + 评测，并把 CSV 一起提交。

重新生成并评测：

```text
python docs/测试/build_registration_cases.py
python docs/测试/score_registration_cases.py
```
