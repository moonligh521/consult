# V0.4：三层裁决与出卡前补述

分支：`feature-V0.4-20261026`。

## 裁决

| 层 | 规则 |
|---|---|
| 程序 | 能明确就定（急症目录、槽位、病名/同义、非歧义症状挂科） |
| 模型 | 程序 UNCERTAIN 才调；`SAFETY` 与 `COMPLAINT` 分用途、分提示词 |
| 兜底 | 安全失败 → SAFE_FALLBACK；挂科失败 → 全科 / 无病种 |

支付 → 派医生路径 0 次模型，只读出卡时落库的 `triage`。

## 出卡补述

`CARD_READY` 时患者仍可发消息：追加描述并重跑 N4/N6，卡片刷新，状态仍为待确认。`CONFIRMED` 后普通病情句仍 1105。
