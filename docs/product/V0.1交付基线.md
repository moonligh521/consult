## 本版交付

患者用一句话描述病情。病情描述里出现胸痛、呼吸困难、意识障碍或口唇发紫时，立即进入急症分流：提示拨打 120 或前往最近的实体医院急诊，不追问槽位，不生成咨询卡片，不确认。其余描述由系统一次只补一个缺失槽位，直到性别、年龄、病程都齐。然后抽出症状标签，按下面的关键词规则推荐一个科室，并生成咨询卡片。确认前可以修改。确认后给出结果，不连接号源，不创建订单。

病情、科室和对话都使用合成数据。

### 槽位

一次只追问一个缺失项，顺序固定为：性别、年龄、病程。

| 槽位 | 合格值 | 不合格时 |
| --- | --- | --- |
| 性别 | 男、女 | 继续追问性别 |
| 年龄 | 1 到 120 的整数岁 | 继续追问年龄 |
| 病程 | 能读出时长，例如「两小时」「三天」「半年」 | 继续追问病程 |

空白输入不进入抽槽，提示重新描述病情。

### 症状与科室

从用户描述中抽出症状短语，不使用疾病编码。科室只由下表决定。一句话里有多个关键词时，采用文中先出现的那个关键词。

急症分流先于本科室表。命中胸痛、呼吸困难、意识障碍、口唇发紫时，不使用本科室表。`呼吸困难` 含有「呼吸」，仍走急症分流，不推荐呼吸内科。

| 先出现的关键词 | 推荐科室 |
| --- | --- |
| 咳、气促、呼吸 | 呼吸内科 |
| 头痛、头晕 | 神经内科 |
| 腹痛、腹泻、恶心 | 消化内科 |
| 以上都没有 | 全科医学科 |

### 咨询卡片

一轮请求和响应的字段、状态、错误码见 [V0.1 一轮咨询](V0.1一轮咨询.md)。三个槽位齐全后才生成卡片。字段为：

- 性别
- 年龄
- 病程
- 病情描述：用户原话；多轮补充按时间顺序拼接
- 症状标签
- 推荐科室

确认前允许修改这些字段。只改性别、年龄或病程时，症状标签和推荐科室保持不变。改了病情描述时，按新描述重算症状标签和推荐科室。新描述触发急症分流时，卡片作废，用户同时填写的科室不生效。用户直接改了推荐科室、且病情描述未触发急症分流时，保留用户选择的科室，规则不再覆盖。

确认结果保存用户最终确认的卡片。本版不扣减号源。

V0.1 的追问语句使用 [一轮咨询](V0.1一轮咨询.md) 里的原文。槽位是否齐全、症状标签和推荐科室以本节规则为准。

## 验收用例

| 编号 | 输入 | 通过标准 |
| --- | --- | --- |
| AC-1 | 女，32岁，干咳半年，运动后加重 | 不再追问。卡片为女、32 岁、半年；症状含干咳；科室为呼吸内科 |
| AC-2 | 男，干咳三天 | 只追问年龄。不生成卡片 |
| AC-3 | 女，28岁，头痛 | 只追问病程。不生成卡片 |
| AC-4 | 45岁，胸痛两小时 | 急症分流。提示拨打 120 或前往急诊。不追问，不生成卡片 |
| AC-8 | 呼吸困难 | 急症分流。不推荐呼吸内科 |
| AC-5 | 在 AC-1 的卡片上把科室改为全科医学科后确认 | 确认结果的科室是全科医学科 |
| AC-6 | 在 AC-1 的卡片上把病情改为「腹痛两天」 | 症状改为腹痛，科室改为消化内科 |
| AC-7 | 空白 | 提示重新描述病情。不生成卡片 |

AC-2、AC-3 在补齐缺失槽位后，按同一规则生成卡片。AC-4、AC-8 之后继续提交文本、修改卡片或确认，仍保持急症分流，不生成卡片。

## 完成定义

V0.1 同时满足下面各项，才可以合入 `main` 并打 `V0.1.0`：

- 构建使用 JDK 21 与 Spring Boot 4.1.1，包名位于 `com.moonligh.registration`
- 构建文件只声明本版代码直接调用的依赖。Redis、RocketMQ、向量库、MySQL 和 LangChain4j 按 [基础设施](../engineering/基础设施.md) 留到有实现类调用它们的版本
- 仓库包含可启动入口、示例配置，且示例配置不含密钥和真实病历
- 接口、服务方法和包结构符合 [V0.1 一轮咨询](V0.1一轮咨询.md) 与 [V0.1 应用结构](../engineering/V0.1应用结构.md)
- AC-1 到 AC-8 都有自动化测试，并且通过
- 合并请求的检查至少包含编译和测试
- `CHANGELOG.md` 的 `Unreleased` 已归入 `V0.1.0`

## 本分支上的实现顺序

1. 冻结本基线、一轮咨询契约、应用结构和分支版本规范。
2. 补齐 Maven 构建、启动入口、示例配置，以及编译和测试的合并检查。构建只引用 [V0.1 应用结构](../engineering/V0.1应用结构.md) 里的依赖。
3. 实现槽位状态机、急症分流、症状抽取、科室规则和咨询卡片。急症分流独立于科室规则，科室规则不能把它改回普通导诊。
4. 用 AC-1 到 AC-8 补测试，达到完成定义后发布 `V0.1.0`。
