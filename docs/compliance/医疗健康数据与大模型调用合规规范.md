# 医疗健康数据与大模型调用合规规范

规范日期：2026-10-21。

本文约束 AI 挂号在采集、调用模型和预约时如何处理个人信息。它不替代 [互联网诊疗服务边界调研报告](互联网诊疗服务边界调研报告.md) 里对互联网诊疗病历的保存要求。普通导诊记录不适用那套 15 年和 3 年期限，除非这次活动在法律上已经构成互联网诊疗病历或过程记录。

## 依据

| 文件 | 本文使用的条款 | 地址 |
| --- | --- | --- |
| 《个人信息保护法》 | 第28条至第31条、第55条 | <http://www.npc.gov.cn/c2/c30834/202108/t20210820_313088.html> |
| 《医疗卫生机构网络安全管理办法》 | 第1条、第13条、第14条；国卫规划发〔2022〕29号 | <https://www.gov.cn/zhengce/zhengceku/2022-08/30/content_5707404.htm> |
| 《互联网诊疗监管细则（试行）》 | 第19条、第21条 | [互联网诊疗服务边界调研报告](互联网诊疗服务边界调研报告.md) |

《个人信息保护法》第28条把医疗健康信息，以及不满十四周岁未成年人的个人信息，列为敏感个人信息。处理敏感个人信息须有特定目的和充分必要性，并采取严格保护措施。第29条要求取得单独同意；法律、行政法规要求书面同意的，从其规定。第30条要求告知处理的必要性及对个人权益的影响。第31条要求处理不满十四周岁未成年人个人信息时取得父母或其他监护人同意，并制定专门规则。

第55条规定，处理敏感个人信息、利用个人信息进行自动化决策、委托处理或向其他个人信息处理者提供、向境外提供，以及其他对个人权益有重大影响的处理，应当事前做个人信息保护影响评估并记录。

《医疗卫生机构网络安全管理办法》第13条要求，应用人工智能开展服务时，上线前评估安全风险并做安全管控。第1条同时以《网络安全法》《数据安全法》《个人信息保护法》为制定依据。医疗机构对其运营网络的网络安全负主体责任，并与信息化参与单位书面约定网络安全义务。

谁决定处理目的和方式，谁是个人信息处理者。只按处理者指示处理的，是受托处理者。模型厂商、云服务商、医院和挂号助手运营方的角色按实际关系确定，不因合同统称「技术供应商」而改变。

## 分开保存

| 记录 | 保存规则 |
| --- | --- |
| 互联网诊疗病历 | 仅在实际开展互联网诊疗时形成。按监管细则第19条，保存不少于 15 年 |
| 互联网诊疗过程记录 | 图文、音视频等，保存不少于 3 年 |
| 普通导诊对话 | 按完成导诊和安全审计所必需的最短期限保存，并在告知中写明 |
| 预约记录 | 按完成预约、退改和争议处理所必需的期限保存 |
| 运行日志 | 不写入完整病历、身份证号和联系方式 |

## 采集与流向

只收集完成当前导诊或预约所必需的信息。

| 数据 | 示例 | 控制 |
| --- | --- | --- |
| 普通查询 | 医院地址、科室介绍 | 尽可能不收集身份信息 |
| 导诊信息 | 症状、持续时间、伴随表现 | 只收必要字段。调用模型前做权限控制 |
| 身份信息 | 姓名、身份证号、手机号 | 放在预约系统内处理，不因导诊而传给模型 |
| 医疗资料 | 检查报告、病历、用药记录 | 默认不上传。确需使用时单独说明目的、取得相应同意，并采取严格保护措施 |
| 预约数据 | 医院、医生、时间、订单状态 | 只向已授权的预约系统传递必要字段 |
| 运行日志 | 错误、调用结果摘要 | 脱敏。禁止完整病历、身份证号和手机号进入日志 |

症状、既往史属于医疗健康信息。处理前告知目的、方式、种类、保存期限和必要性，并与普通服务条款分开取得单独同意。用户可以查询、更正、撤回同意和提出删除。依法应当保留的记录，在告知中说明保留原因和期限，不因删除请求而违反法定保存义务。

不满十四周岁未成年人的症状和身份信息，按第31条取得监护人同意，并适用专门规则。儿童急症场景仍优先走 [安全处置规范](AI导诊风险识别与安全处置规范.md)，不因授权未完成而延迟紧急提示。

## 模型与第三方

调用大模型属于委托处理或向其他处理者提供时，事前完成个人信息保护影响评估。协议写明处理目的、期限、方式、种类、保护措施和审计。模型服务商不得将患者信息用于约定以外的训练，除非另有合法依据并重新告知和评估。

医院信息系统、预约平台和模型服务商的权限分开。号源与预约状态以医院或预约平台的返回为准。模型不能写入号源，也不能读取与本次导诊无关的病历。

使用境外模型、境外备份，或境外人员能够访问患者数据时，按《个人信息保护法》第55条第（四）项评估向境外提供个人信息，并同时评估医疗卫生数据的适用要求。未完成评估前，不把症状、身份和病历送到境外。

安全事件发生后，按适用的网络安全和个人信息保护义务处置，并通知受影响的合作医院。
